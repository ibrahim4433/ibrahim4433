## 🧪 Security Labs & Engineering Projects

Here are select repositories demonstrating hands-on work in security engineering, reverse engineering, and infrastructure automation:

- 🛡️ **[Secure-Static-App-Cloudflare](https://github.com/ibrahim4433/Secure-Static-App-Cloudflare)**: Universal serverless edge distribution architecture built on Cloudflare Workers with token header verification, direct CDN delivery, and zero server costs.
